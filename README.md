# Ритм — помощник для сна, питания и привычек (Telegram Mini App)

## Запуск на компьютере

```bash
npm install
npm run dev
```

Открой http://localhost:5173. Вне Telegram всё работает, кроме вибрации и облачной синхронизации.

## Как подключить к Telegram

1. **Собрать приложение:** `npm run build`, готовые файлы будут в папке `dist`.
2. **Выложить `dist` на любой хостинг с HTTPS** (Telegram требует https):
   - самый простой вариант — перетащить папку `dist` на https://app.netlify.com/drop;
   - или GitHub Pages / Vercel / Cloudflare Pages.
3. **Создать бота:** в Telegram открой @BotFather → `/newbot` → придумай имя.
4. **Привязать приложение:** в @BotFather выбери `/mybots` → свой бот → *Bot Settings* → *Menu Button* → вставь ссылку с хостинга.
   Можно ещё сделать `/newapp`, тогда у приложения будет своя ссылка вида `t.me/твой_бот/app`.
5. Открой бота и нажми кнопку меню. Готово.

## Что внутри

- **Сегодня:** калории и КБЖУ, сон, вода, шаги, привычки, настроение, вес, совет дня.
- **Сон:** «Ложусь» / «Проснулся» в один тап, оценка сна, недосып, регулярность режима, графики, калькулятор циклов.
- **Питание:** норма по формуле Миффлина — Сан Жеора, приёмы пищи, база из 100+ продуктов, поиск, избранное, свои продукты и блюда, копирование со вчера, вода, интервальное голодание.
- **Привычки и цели:** расписание по дням, счётные привычки, серии, карта активности, цели с шагами, числом или весом.
- **Прогресс:** шаги, вес с трендом и прогнозом, выводы по данным, 19+ достижений.

Данные хранятся в браузере и дублируются в облако Telegram (CloudStorage), поэтому одинаково открываются на телефоне и на компьютере.

## Структура

- `src/screens` — экраны
- `src/components` — интерфейс, графики, шторки
- `src/lib` — расчёты, даты, Telegram, синхронизация
- `src/data` — база продуктов и шаблоны привычек
- `src/store.ts` — все данные и действия
